Dataset Access

The dataset files are not included in this repository due to their large size.

You can download the dataset from the following Google Drive link:

Google Drive Dataset:
https://drive.google.com/file/d/1SS8oDolXaYnqv6alwVoOwyvQBpbaY8Sa/view

How to prepare the data

1. Download the dataset from the link above.
2. Extract the main file.
   After extraction, you will get approximately 30+ zip files.
3. Extract all of those zip files.
4. Place the final extracted folders/files inside the "data/" directory of this project.
5. Open the notebook and set the correct path in the "base_dir" variable to the data location.
6. Run the notebook.

«Note: The notebook expects the data path to be specified in the "base_dir" variable.»
